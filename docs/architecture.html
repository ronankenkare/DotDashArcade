Responsibility split

The dependency graph is intentionally small: SwiftUI owns presentation and navigation, while GameState owns the live game.

UI

SwiftUI views

Present the home screen, persisted appearance control, score bar, help overlay, mode control, and Canvas drawing surface.

GS

GameState

Calculates movement and hit quality, changes difficulty, emits feedback, and publishes renderable state.

OS

Platform services

Supply frame timing, haptic feedback, scene lifecycle events, system appearance, and durable key-value storage.
